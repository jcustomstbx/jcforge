# AI Editor — Notice

The AI Editor is still being built. It is not finished software.

- Output quality varies clip to clip. Captions, timing, and effect choices can be wrong.
- Watch every clip back before you post it or send it to anyone. Do not trust it blind.
- If a clip looks off, that is expected right now, not a sign your setup is broken.

## API keys

The AI Editor needs your own API key (Gemini and/or Anthropic/Claude). Optional: ElevenLabs for generated sound effects.

- These are your keys, on your own billing. JCForge does not see or pay for any of it.
- Only add a key if you are comfortable with real charges landing on that account.
- Keys are stored locally on your machine, not sent anywhere except the AI provider you picked.
- You can remove a key at any time from Settings.

If you are not sure, don't add a key yet. The rest of the app (recording, detection, clip capture) works fully without one.
